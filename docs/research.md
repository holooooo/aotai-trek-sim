# 调研笔记：鳌太线与游戏化取舍

本文记录《鳌太线冬季穿越模拟器》制作时参考的公开资料，以及把这些资料转化为游戏机制时所做的取舍。

> **使用说明**
>
> - 事实性内容整理自下列公开报道与资料，**未能逐条核对原文**；数字在不同来源间说法不一时，会注明"说法不一"。
> - 部分来源为自媒体整理，数据未经核实，仅作背景参考，已在文中标注。
> - 本项目**不是**出行参考。鳌太线位于太白山国家级自然保护区，自 2018 年起禁止穿越。

## 1. 线路概况

- 起止：鳌山（约 3476 m）— 太白山拔仙台（约 3767–3771 m，青藏高原以东最高点）。
- 规模：两端直线距离 40 余公里，实际徒步约 **120–170 公里**（说法不一）；沿途连续翻越 **17 座海拔 3400 m 以上的山峰**，平均海拔约 3566 m；大部分路段为无人区。
- 起点：塘口村，海拔约 1740 m，十几公里内要爬升 1700 多米。
- 综合来源：[Wikipedia: Aotai trail](https://en.wikipedia.org/wiki/Aotai_trail)、[搜狐](https://www.sohu.com/a/85403454_416654)、[人民日报客户端](https://www.peopleapp.com/rmharticle/30051159988)。

**标准途经点（自西向东）**：

塘口 — 2900营地 — 鳌山大梁 — 导航架 — 药王洞 — 荞麦梁 — 水窝子营地 — 飞机梁 — **2800营地** — 金字塔 — 西塬 — 太白梁 — 大石河营地 — 东塬 — 万仙阵 — 雷公庙 — 跑马梁 — **大爷海** — 拔仙台

- **2800营地**是全线最关键的下撤点：南坡下撤至核桃坪，北坡可下白云峡；有林子挡风。
- **大爷海**已在景区范围内，有信号、有房子、有人，是"穿越到此为止"的第一个安全节点。

## 2. 地形

- 约 **30% 为松散石海**：石头上不会留下脚印，起雾后极易迷路。
- 其余多为刃脊、冰雪覆盖的山脊与高山塬，并有第四纪冰川遗迹（游戏中以万仙阵的石阵呈现）。
- 全线**无补给、无信号**（进入景区范围的大爷海一带才有信号）。
- 来源：[什么值得买](https://post.smzdm.com/p/ako9wn5k)。注意：这是自媒体整理，部分数据未核实，本项目仅取其定性描述。

## 3. 气候

- "一日四季，十里不同天"。
- 冬季鳌山一带夜间可降到**零下二十七八度**；太白山高山区极端最低气温曾**低于零下 30℃**。
- 大风：10 级以上的风可以吹翻帐篷。
- 两大主要风险：**大雾导致迷路**、**低温导致失温**。
- 来源：[人民日报客户端](https://www.peopleapp.com/rmharticle/30051159988)、[虎嗅](https://www.huxiu.com/article/4826144.html)。

小结（游戏据此设计）：

1. 失温是头号杀手，往往叠加**湿冷 + 大风 + 疲劳 + 饥饿**。
2. 大雾、石海、夜晚让人"找不回路"，电子设备（充电宝、手机）在低温下不可靠。
3. 2024 年与 2025 年的两起事件，当事人都是在 **2800 营地—核桃坪**一线被发现的：这条下撤路线最重要，但本身也并不轻松。
4. 为了躲避处罚而开飞行模式，会让救援失去最后的定位线索。

## 5. "神秘园"系列

- B 站 UP 主"神秘园"的鳌太线系列共 3 期，累计播放超千万；以**真实事件为原料、剧情片式叙事**。
- 系列中的人物：53 岁的**吴先生**原本能够获救，最终遇难；被困 8 天的**陈某放**靠烂野果、树叶和过期腐乳生还；帮陌生人搭帐篷的**小牟**。
- UP 主的建议：遇险后**不要乱走，在 2800 营地这样的地方原地等待救援**。
- 来源：[凤凰网采访](https://news.ifeng.com/c/8q4IvNVgZFi)、[界面新闻](https://www.jiemian.com/article/13908431.html)、[人人都是产品经理](https://www.woshipm.com/share/6332310.html)。

游戏里的老吴、老陈、小牟三位 NPC 受这条线索启发，但**人物均为化名或虚构**，其年龄、籍贯与具体情节是游戏的改编，不应当作事实陈述。

## 6. "门口没有烤肠的山，不要爬"

- 含义：有烤肠摊的山，通常是**开发成熟的景区**——有索道栈道、有护林员和救援、有手机信号、有人。门口连烤肠摊都没有的山，往往意味着以上全部缺位，出事时没人兜底。
- 出处：调研中**未能找到权威的原始出处**，只能确认它是网络上流传的说法，这里仅取其含义，不作考证。
- 游戏中的落点：山脚小卖部的烤肠永远"已售罄"；在管护站前回头会得到"门口有烤肠"的最佳结局；严重失温或压力过高时会出现"烤肠摊"的幻觉。

## 7. 游戏化取舍

下表把研究结论映射为游戏机制。机制的具体数值见 `src/sim/`、`src/data/`，多为**游戏化近似**，用来制造"后果可感知"的体验，而不是物理或医学上的精确模型。

| 现实线索 | 游戏机制 | 实现要点（近似值） |
| --- | --- | --- |
| 元旦假期、冬季事故集中；2026-01-02 事件 | **元旦开局**：12月31日 05:30 在塘口出发 | 天气日程半脚本化：第 1 天午后起雾；第 2 天午后冷锋 → 暴风雪；第 3 天减弱 + 午后雾；第 4 天大风；之后随机 |
| 管护站、禁令、罚款；开飞行模式躲监测 | **管护站抉择**：钻缺口进山（可选飞行模式），或回头得"门口有烤肠"结局 | 飞行模式下手机无法求救；违规会被罚款，结局页显示 ¥5000 罚款、¥80000 救援费（均为游戏设定） |
| 一日轻装速通攻略；2026-01-02 事件 | 商店里的 25L 一日背包装不下帐篷睡袋；NPC"速通四人组" | 劝返 / 提醒关飞行模式会改变他们的命运 |
| 普通气罐低温失效，无法烧雪化水 | 普通气罐 vs 高山防冻气罐 | 气温低于约 -6℃ 且气罐未贴身保暖时，普通气罐有 45% 概率点不着 |
| 2025年2月少年：充电宝冻死机 | 严寒中充电宝随机"冻死机" | 气温低于 -15℃、设备未贴身、不在帐篷里时随时间累积概率；老驴自动把电子设备揣怀里 |
| 反常脱衣（重度失温的典型症状） | 核心体温低于约 32.6℃ 触发"浑身燥热"事件 | 选择"脱掉外套"会立即掉体温；选择裹紧衣物才能压住 |
| 少年吃牙膏、出现幻觉；极端环境下的认知障碍 | 压力高（>78）或体温低（<33.8℃）且处于夜晚/大雾时出现幻觉 | 幻觉内容（烤肠摊）是游戏的设计，并非报道所述 |
| 石海无脚印、大雾迷路 | 偏离路线过远进入"迷路"状态；雾中"沿路走"失效 | GPS 放大判定距离，老驴更不容易迷路 |
| 大风能推倒人、吹翻帐篷 | **阵风 + 按住"稳住"**；帐篷有抗风等级 | 有效风速约 12.5 m/s 以上才会出现阵风；三季帐约 11 m/s、四季帐约 22 m/s 的抗风数值 |
| 帐篷朝向（尾部迎风、背风坡） | 放置帐篷时旋转朝向，并显示评价 | 尾部迎风有效风速 ×0.7，侧面 ×1.35，门朝来风 ×1.1 且帐内更冷；大学生"看不出来哪样摆更好" |
| 热食热水有用，吃雪、冷水、白酒有害 | 吃喝直接影响核心体温 | 热水泡面 / 自热饭 / 保温杯热水回升；吃雪约 -0.3℃；白酒使散热 ×1.25，持续约 2 小时 |
| 湿冷 + 大风 + 疲劳 + 饥饿叠加导致失温；棉质吸水 | 出汗 / 潮湿模型；棉质衣物湿后保暖力很低 | 走路时穿羽绒服会加速出汗；停下不穿保暖层则快速失热 |
| 2800 营地是最重要的下撤点 | 2800 营地附近可选**南坡下撤到核桃坪**（约 10 km） | 沿途有"羚牛"事件；终点触发"南坡下撤"结局 |
| UP 主：遇险后原地等待救援 | 求救后"原地等待"才是正解 | 基础约 6–36 小时（由所处位置决定），恶劣天气、定位不精确会更久；离开报告位置会延长甚至扑空 |
| 2026-01-02：信号只被模糊记录一次 | 手机需有信号且未开飞行模式；北斗卫星通讯器可在无信号处发出精确坐标 | 导航架、太白梁、大爷海等少数点位有信号（大爷海最好） |
| 无补给点、冬季夜长 | 食物 / 水分 / 燃料需要自己规划；夜间能见度低 | 日出约 07:50、日落约 17:50（游戏设定） |

### 哪些数字是近似的

- **路线**：游戏内全程约 113 km（现实说法不一，约 120–170 km）；海拔、里程均为"据公开资料整理的近似值"。游戏地形 1 体素 ≈ 水平 40 m / 垂直 25 m（垂直方向略有夸张）。
- **气温**：以 3500 m 处冬季日均约 -13.5℃ 为基准，叠加昼夜 ±6℃、随海拔递减（约 0.0062℃/m）、天气修正；风寒采用常见的风寒指数公式。
- **生理**：核心体温、体力、饱食、潮湿等均为简化模型；"低于 35℃ 失温、低于 28℃ 死亡"是游戏阈值。
- **时间**：现实 1 秒 = 游戏 4 分钟。
- **价格、罚款、救援费用、概率**：均为游戏设定，不代表真实数据。

## 10. 本次扩展核对的事故与改编边界

### 2018年：独自探路后失联

西安晚报及华商报的2018年5月3日报道记载，三人同行，一人独自探路时走错路线，失联近三天，5月2日被找到并安全下山。天气较好、装备较齐全是报道引用救援方的说法，不代表具备这些条件就安全。未采用未经核实的精确发现时间、位置或救援账单。

来源：[澎湃转载西安晚报](https://www.thepaper.cn/newsDetail_forward_2108934)、[人民政协网转载华商报](https://www.rmzxw.com.cn/c/2018-05-03/2042213.shtml)。

游戏使用虚构岔路情境，选择保持队伍联络核对方向、独自试探或下撤；不复演报道当事人的行动，不让选择保证获救。

### 2021年：五一极端天气与失温

陕视新闻报道，5月2日两名驴友在鳌太线遭遇极端恶劣天气，其中一人失温死亡。报道未给出精确核心体温、完整病程或可用于游戏的气象参数；不与同月其他队伍的报道合并。

来源：[澎湃转载陕视新闻](https://www.thepaper.cn/newsDetail_forward_12540347)、[华商网转载陕视新闻](https://news.hsw.cn/system/2021/0506/1321136.shtml)。

游戏仍发生在既定冬季背景，提炼“季节印象和运动发热不能抵消风、湿冷与疲劳”的机制，安排停止推进、检查保暖层和继续赶路的代价，不虚构现实病例的数值。

### 2022年：暴雨中走散，搜寻尚未结束

封面新闻2022年6月8日报道，三人遭遇暴雨，两人撤回求救，一人失联；截至该报道仍在搜寻。警方表示一行人此前曾被劝返，之后改从其他入口进山。公开资料在此时间点没有确认最终结局，因此档案不写成死亡或获救，也不编造分离的确切原因。

来源：[封面新闻](https://www.thecover.cn/news/9278529)。

游戏只借鉴“求救者下撤不等于失联者获救”的信息链条，虚构路人交付最后目击位置与时间的情境。记下、通信移交、下山后实际移交分别记录；即使获得“把消息带下山”尾声，也不宣告被寻找者的结局。
