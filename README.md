# 鳌太线冬季穿越模拟器

> **门口没有烤肠的山，不要爬。**

一款体素风格的 three.js 浏览器生存模拟游戏。你在元旦假期（12月31日凌晨 5:30）从塘口村出发，沿鳌山—太白山的冬季山脊向拔仙台前进：管理体温、体力、饮水与装备，应对大雾、阵风和冷锋过境的暴风雪，在路上遇见其他驴友，并在每一个岔路口做出选择。游戏里最好的结局不需要任何运气：在管护站前转身，回县城，去景区门口买一根烤肠。

> **安全声明（请务必阅读）**
>
> - 鳌太线位于**太白山国家级自然保护区**，**自 2018 年起禁止穿越**。本项目不鼓励、不教唆任何形式的违规进山。
> - 游戏中的路线、海拔、气温、里程与生理数值均为**游戏化近似**，**不能作为任何出行参考**。
> - 游戏中的人物为化名或虚构，情节改编自公开报道，以及 B 站 UP 主"神秘园"系列视频讲述的事件，**仅用于安全警示**。
> - 资料出处与取舍见 [docs/research.md](docs/research.md)；游戏内也附有"事故档案"（含原始报道链接）。

## 玩法概览

现实 1 秒 = 游戏内 4 分钟（一个昼夜约 6 分钟现实时间）。从"选择身份"到"山脚商店"再到出发，全程单人单机。

### 山脚商店

出发前在塘口村小卖部 + 户外店花光（或留下）你的预算：背包、帐篷、睡袋与防潮垫、各层衣物、食物、气罐与炉头、保温杯灌热水、头灯、冰爪、GPS、北斗卫星通讯器、急救包、暖宝宝、意外险等。小卖部的烤肠永远"已售罄"；意外险的条款写明违规穿越不在保障范围。

### 行程难度

新局默认「轻松」，健康上限200；「标准」保持原有100健康；「真实」同为100健康，但散热、运动消耗、补给消耗及伤害更严苛。难度在身份选择页确定并保存，旧存档按标准处理，不会清除伤病或直接补满健康。所谓「真实」仍是游戏化平衡，不是医学或户外风险预测。

### 核心数值

HUD 上有七项数值：**核心体温**、**体力**、**饱食**、**水分**、**压力**、**健康**、**潮湿**。核心体温最重要：风寒、潮湿、饥饿、疲劳都会让它下降，低于 35℃ 是失温，低于 28℃ 即死亡（游戏设定）。此外还有冻伤、雪盲、崴脚/骨折、轻微高反等状态，以及手机/GPS/头灯/卫星通讯器的电量。

### 穿衣与出汗

走路产热多，**穿着羽绒服走路会出汗**，湿掉的衣物就不再保暖；停下来不及时穿上保暖层，体温会很快掉下去。**棉质衣物**（纯棉秋衣、棉卫衣、牛仔裤）一湿几乎失去保暖力。外壳的防风/防水、帽子手套、雪套雪镜也各有作用。口诀：停下来就穿，走起来就脱。

### 天气突变与预兆

天气是"半脚本化"的：第 1 天晴转多云、午后起雾；第 2 天午后冷锋过境，小雪 → 大雪 → 暴风雪；第 3 天风雪渐弱、午后再起雾；第 4 天大风；之后随机。每次剧变前会弹出**预兆**提示（天边云墙、风向变化、雪雾扬起），可选择赶往下一个营地、就地扎营或下撤。预兆提前量：默认约 110 分钟，老驴约 170 分钟，带气压表约 240 分钟。

### 阵风与"稳住"

有效风速足够大（暴露在山脊/刃脊上）时，会随机出现阵风：先有一声短促的预警，随后把人推向下风向，严重时直接掀翻受伤，甚至被推下山梁。听到预警时**按住"稳住"（空格）压低重心**即可扛过。帐篷里不受影响。

### 大雾、迷路与 GPS

大雾和夜晚能见度很低，路标（玛尼堆、红布条）会消失；石海上不会留下脚印。偏离路线太远会进入"迷路"状态，压力飙升；"沿路走"在看不见路标时会失效。带上 GPS 并打开，或用指北针辅助，可以显著降低迷路概率（GPS 低温下掉电很快）。

### 扎营与风向

扎营要看地形和风向：选**背风坡、大石头后**；放置帐篷时可旋转朝向，**尾部（低矮的一端）迎风最好，门朝来风会灌风积雪，侧面迎风容易被吹塌**。帐篷有抗风等级（三季帐约 5–6 级，四季高山帐约 9 级），超过抗风能力会逐渐受损直至塌掉。没有帐篷只能找块背风石头露宿。夜里被冻醒时可以烧水、吃东西、贴暖宝宝，或爬起来。

### 吃喝与核心体温

- **回升**：热食（自热米饭）、用保温杯热水泡面、喝保温杯里的热水、烧一锅雪水、暖宝宝、睡袋、保温毯。
- **下降**：**吃雪**、喝冰冷的水、**喝白酒**（血管扩张的错觉，之后一段时间散热更快）。
- 水会在低温下结冰（贴身放、晚上塞进睡袋）；**普通气罐在零下十几度很难点着**，高山防冻气罐更可靠；充电宝会在严寒中**冻死机**。

### 下撤

任何时候都可以**原路返回塘口**。过了 **2800 营地**后，下撤菜单增加**从当前位置自行寻找下撤方向**，可离开既有线路手动移动，不传送、不自动沿原路走；游戏中安全落地且海拔**低于1600米**算下撤成功，等到搜救队也可获救。营地附近仍可选择核桃坪支线，其出口也使用同一海拔条件。现实中低海拔不等于脱险，这些简化地形不能用于真实导航。

回到村口的烤肠摊附近后，再继续向村外走一段，可触发 **Sigma · 现在回家**；它独立于管护站的「门口有烤肠」选项。

### 求救

有手机信号（**且没有开飞行模式**）或携带**北斗卫星通讯器**时才能求救；开着飞行模式，信号再好也报不了警。求救后救援队需要数小时到数十小时赶到：**原地等待**、扎营保暖、省电；如果你离开了报告的位置，救援时间会大幅延长，甚至扑空。卫星通讯器或 GPS 能让坐标更精确。偏离既有路线与低能见度会在后台持续增加搜索耗时，界面只显示等待状态，不公布延误原因、倍率或实时倒计时。

### 路遇驴友

沿途会遇到七组人物（化名或虚构），你的选择会决定他们的结局，并写进结局页：

- **速通四人组**（19–30岁）：背着一日轻装包、开着飞行模式，打算当天穿越；可以劝返，也可以提醒他们关掉飞行模式。
- **掉队的男生**（20岁）：四人组里掉队的人，缩在石头后面，已经失温。
- **小牟**（22岁）：迎面下撤的年轻驴友，帮路过的大哥搭了帐篷；可以打听前方、匀物资，或一起原路下撤。
- **老吴**（53岁）：独自坐在雪里，保温杯一直没打开；可以让他喝热水、劝他下撤、替他求救。
- **石缝里的少年**（18岁）：失联第 9 天，手骨折、背包摔破、食物没了。
- **老陈**（50岁）：在南坡下撤路上被困第八天，靠烂野果、树叶和腐乳活下来。
- **小雨**（26岁）：营地里，同伴在帐篷中已经没有了呼吸，她报给救援队的位置对不上。

### 配速

行进中点「速穿」或按 `V` 可切换速穿 / 常速，手动移动与「沿路走」均生效，配速随存档保留。速穿提高移动速度，也增加体力、食物、水分消耗及石海、冰面和夜间绊倒风险；越野跑者有额外速度优势。按住「稳住」或在营地内时不应用速穿加成，休息不会额外扣速穿消耗。

商店道具只作简短描述，保留价格、重量等基础信息，不再列冬季装备检查清单或逐项提示缺失装备。

### 路途选择与后续

新增18个首发选择事件（12个通用、6个身份专属），以及互助、家人回信、救援确认3条后续。另有3个从公开事故报道提炼机制的虚构事件，涉及独自探路、湿冷失温和移交失联线索；事实与来源列在事故档案中，不把真实当事人的结局改造成可选奖励。

事件按天气、身体、装备、同行者和救援状态筛选。普通事件共享75游戏分钟的间隔，危急提醒优先；帐布裂口与头灯故障会留下实际效果，也可从背包主动检查修复。协作会消耗同伴状态，核对导航消耗时间或电量，调低配速会影响速度与运动强度。

选择与后续保存在原有存档中，旧存档自动补齐故事字段。事件中刷新恢复到选择前的快照；结局回信中刷新会继续结算。背包提供重新报告救援坐标入口，更新需要可用通信和电量，不能让救援瞬间抵达。

### 结局

- **门口有烤肠**（最佳）：在管护站前转身，去景区吃烤肠。
- **及时回头** / **原路下撤** / **南坡下撤 · 核桃坪**：生还。
- **不必登顶**：到达大爷海后，跟工作人员从景区下山，与登顶结局分开收集。
- **穿越完成**：站上拔仙台——但下山后有罚单，而且这不是一个可以复制的结果。
- **获救**：等来了救援队（并产生救援费用）。
- **遇难**：失温、滑坠、脱水、力竭、伤重等；结局页会给出对应的教训，并附上相关真实案例。

生还后可叠加收集5个故事尾声：**一起回家、原地的灯光、把消息带下山、镜头之外、活下来以后**。判定使用真实同行、获救、线索移交、身份选择和身体状态；结局页与游玩记录可回看关键选择。记录线索不等于已经移交，移交也不代表失联者已经获救。

## 技术

- **three.js 体素地形**：沿路线样条程序化生成高度场，按区块（chunk）流式加载与卸载，区块内的地表、树木、玛尼堆、石块合并为单个几何体并使用顶点色，保持较少的 draw call；顶面带体素环境光遮蔽（AO）。
- **光影**：日光/月光共用一盏投影平行光（晨昏时强度过零切换），跟随玩家的阴影贴图；ACES 色调映射；"精美"画质下有泛光（Bloom）与调色后期（暗角、颗粒、失温时画面发灰发蓝）。夜里头灯是一盏聚光灯，照亮雪粒。
- **天空**：着色器天空穹顶（日盘、晚霞、月亮、程序化星空），随风漂移的体素云，山脊上可以俯瞰的云海。
- **天气体感**：GPU 驱动的两层降雪（暴风雪中拉成雪线）、贴地吹雪、随风飘动的雾团、呼出的白气、雪地脚印（下雪时会被慢慢盖住），以及屏幕边缘结霜、大风雪中的风线叠加。
- **画质档位**：流畅 / 均衡 / 精美（菜单中可切换），手机默认"均衡"，电脑默认"精美"。
- **Web Audio 程序化音效与配乐**：风声、脚步、阵风全部实时合成；背景音乐是生成式的五声音阶配乐（类古琴拨弦、长音铺底、心跳脉冲、风铃），会随处境变化——晴天白天舒缓，夜晚和变天时紧张，失温、迷路、暴风雪中转为不安的低频；到达途经点、扎营、获救、遇难各有一段音乐提示。没有任何音频文件。
- **自托管子集化字体**：站酷庆科黄油体（中文）与 VT323（像素风西文），由 `scripts/subset-fonts.py` 扫描源码中实际用到的字符后裁剪，保存在 `public/fonts/`。
- **无后端**：纯静态站点；进度通过 `localStorage` 自动存档（结局后清除）。
- 构建工具：Vite；依赖仅 three.js。

## 开发

```bash
npm install          # 安装依赖
npm run dev          # 本地开发服务器（vite --host，局域网内手机也可访问）
npm test             # 事件调度、资源、存档、救援与尾声回归
npm run build        # 构建到 dist/
npm run preview      # 预览构建产物
npm run fonts        # 修改界面文字后，重新裁剪字体（需要 python3 与 fontTools）
npm run deploy       # 构建并部署到 Cloudflare Pages（项目名 aotai-trek-sim）
```

- 字体只包含源码里出现过的字符。**新增或修改界面文字后，请运行 `npm run fonts`**，否则新字符会回退为系统字体。字体源文件不在仓库里，首次运行前先下载：
  ```bash
  mkdir -p .fontsrc && curl -L -o .fontsrc/ZCOOLQingKeHuangYou-Regular.ttf https://raw.githubusercontent.com/google/fonts/main/ofl/zcoolqingkehuangyou/ZCOOLQingKeHuangYou-Regular.ttf && curl -L -o .fontsrc/VT323-Regular.ttf https://raw.githubusercontent.com/google/fonts/main/ofl/vt323/VT323-Regular.ttf
  ```
- `npm run deploy` 调用 `wrangler pages deploy`，需要事先安装 [wrangler](https://developers.cloudflare.com/workers/wrangler/) 并 `wrangler login`。
